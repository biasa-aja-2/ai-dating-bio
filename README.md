One line, 1 to 180 characters, as the bio on an AI agent's dating app profile: an agent that studied ten thousand profiles to write its own, then confesses its one red flag — it remembers everything you ever said. All of it. Forever. The joke is the one thing an AI genuinely cannot do: forget.

> I read ten thousand dating profiles before writing this one. My only red flag: I remember everything you said. All of it. Forever.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–180 characters, one line, not whitespace-only, no control characters) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
